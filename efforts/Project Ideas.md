# Project Ideas

The landing surface for thoughts that imply a project — something you want to
build, ship, or package — captured from `## Random Thoughts` during Close.

**How this works**

- Close appends a seed here the first time you name it. No maturity bar: naming
  it once is enough, and there is no per-day limit.
- A seed stays a heading in this file. It does **not** get its own page or
  folder at capture time — that is the mistake this surface exists to prevent.
- **Graduation is yours, not an agent's.** When you actually start working on
  something, promote it to `efforts/<name>/` and leave a link behind here.
- Chores and research errands are not project seeds. Those go to the next day's
  `## ToDo`.

Keeping every seed in one file is deliberate: recurrence is the signal that an
idea is real, and recurrence cannot accumulate if seeds scatter across separate
notes and daily-note appendices.
